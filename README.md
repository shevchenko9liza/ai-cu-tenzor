## Статус на 25 октября 2026

Лабораторная 4 перенесена из прежней рабочей папки без изменения результатов. В ней остаются личные разделы студентки. Лабораторная 5 — первая версия по выбранному пользователем сценарию; остальные проектные решения предложены агентом и ждут содержательной обратной связи. КТ-3 требует согласования команды, личных прохождений и итоговой презентации.

Публикация в GitHub делает результаты доступными по ссылке. Подтверждения, что преподаватель принимает GitHub вместо GitLab, пока нет. Это не отметка о сдаче или оценке.

В прототипе используются только вымышленные данные. Настоящий архив, модель прогноза, интеграции и результаты пользовательского тестирования здесь отсутствуют. Работоспособность интерфейса не доказывает спрос и пригодность реальных данных.
