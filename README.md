# Тензор · учебные работы

Материалы Елизаветы Шевченко по курсу «ИИ-центричное предпринимательство», осень 2026.

«Тензор» исследует, как помогать промышленным предприятиям заранее предупреждать отказы оборудования. Основной сценарий КТ-3: **инженер ТЭС разбирает предупреждение по питательному насосу и готовит задание на диагностику или обслуживание**. Проверка архива сохранена как вспомогательная подготовка пилота.

## Статус на 25 октября 2026

Лабораторная 4 сохранена, отдельно подготовлен черновик выводов для личной проверки. Основной прототип лабораторной 5 и КТ-3 перестроен вокруг питательного насоса ТЭС: сводка, интерактивная 3D-схема, показания с пояснениями и следующим шагом, объяснение сигнала, выбор действия, задание, файл и журнал. Есть отдельная ветка отсутствующих данных с уточнением и повторной проверкой. Подготовлена версия 8 презентации в оформлении КТ-2: 22 слайда с наглядными схемами сценария, 11 экранами и кликабельными ссылками. Новый логотип встроен в дашборд.

Предыдущий [макет проверки архива](lab05/archive-check.html) и [его журнал](lab05/archive-decisions.md) сохранены. Переданный ранее отчёт относится к архивному сценарию. Самостоятельное прохождение нового макета, командное согласование и репетиция ещё не подтверждены. [Пошаговая проверка новой версии](lab05/decisions.md).

Публикация в GitHub делает результаты доступными по ссылке. Подтверждения, что преподаватель принимает GitHub вместо GitLab, пока нет. Это не отметка о сдаче или оценке.

Показания и выводы панели вымышлены. Раздел «Схема» содержит два экрана с обрезанными служебными полосами из предоставленных Елизаветой материалов предприятия от 1 марта 2022 года. ПН-01 учебно связан с обозначением ПЭН-1А; текущая неисправность и актуальность схемы не подтверждены. Настоящий архив, модель прогноза, интеграции и результаты пользовательского тестирования здесь отсутствуют. Работоспособность интерфейса не доказывает спрос и пригодность реальных данных.
