Статус на 25 октября 2026

Лабораторная 4 перенесена из прежней рабочей папки без изменения результатов. Отдельно подготовлен черновик выводов и решений по незаполненным разделам; личная проверка и решения студентки ещё не получены. Лабораторная 5 — первая версия по выбранному пользователем сценарию; остальные проектные решения предложены агентом и ждут содержательной обратной связи. Для КТ-3 готовы 12 слайдов в оформлении КТ-2, заметки выступающего и PDF. Следующий шаг: проверка с пользовательницей, согласование команды, личные прохождения и репетиция.

Публикация в GitHub делает результаты доступными по ссылке. Подтверждения, что преподаватель принимает GitHub вместо GitLab, пока нет. Это не отметка о сдаче или оценке.

В прототипе используются только вымышленные данные. Настоящий архив, модель прогноза, интеграции и результаты пользовательского тестирования здесь отсутствуют. Работоспособность интерфейса не доказывает спрос и пригодность реальных данных.
