Готовность КТ-3: питательный насос ТЭС

Основание: переданный чек-лист недели 8, источник KT3 в реестре. Статус на 25.10.2026. Направление изменено по запросу пользовательницы: основной результат — решение по предупреждению и задание на обслуживание.

Два артефакта для сдачи

  • Онлайн-прототип и один автономный HTML для скачивания.
  • Исходные схемы ПДУ / ПЭН-А,Б привязаны к учебному ПН-01; дата и ограничения указаны.
  • Презентация в стиле КТ-2: PPTX v8: 22 слайда, 11 экранов прототипа и ссылки на артефакты.
  • Команда и пользовательница проверили содержимое новой версии.
  • Проверен точный дедлайн и место загрузки в LMS.
  • Оба артефакта фактически отправлены преподавателю.

Публикация файлов в GitHub не является сдачей. Просмотр исходного HTML на GitHub не является запущенным онлайн-прототипом. Для сдачи без архива используется рабочая онлайн-версия GitHub Pages. Яндекс.Диск хранит презентацию и дополнительные документы. Файлы и ссылки для сдачи.

Сопоставление с критериями

Критерий Вес Что есть Что ещё проверить
K1: пользователь, задачи, границы 20% Инженер ТЭС, питательный насос, задача, результат и объём; гипотезы сегмента, ценности и оплаты Уместность насоса и роли с командой и инженером; реальные основания спроса ограничены
K2: USM 25% Действия, ответы продукта, варианты, ошибки, возвраты и границы Совместное согласование карты и приоритетов
K3: UX 25% Сквозной путь ПН-01, отсутствие данных ПН-03, ошибки и продолжение, файл и журнал Самостоятельное прохождение без подсказок; техническая проверка не заменяет это
K4: обратная связь экспертов 10% Задания на проверку и вопросы экспертам Сама встреча и зафиксированные замечания ещё впереди
K5: подача 10% Слайды, заметки, демонстрационный сценарий и схемы оборудования Репетиция с таймером и проверка комплекта на другом устройстве
K6: качество результата с ИИ 10% Макет и документы согласованы; учебные данные и границы явно указаны Проверить, понятен ли итог человеку и может ли он сам пройти путь

Баллы заранее не присваиваются. Backend, реальная модель и интеграции для этой контрольной точки не обязательны. Большое число экранов само по себе не повышает оценку.

Четыре вопроса презентации

  • Для кого первая версия и кто владелец сценария.
  • Какие задачи образуют один результат и почему выбран этот путь.
  • USM: действия, ответы, альтернативы, возвраты и объём.
  • Что проверять в интерфейсе и какое задание дать человеку.

Отдельные оставшиеся действия

  • Пользовательница лично прошла новую версию и внесла замечания в журнал. Это также закрывает личную часть лабораторной 5.
  • Команда согласовала основной сценарий и USM. Переписка с пользовательницей не подменяет командное согласование.
  • Проведена репетиция: выступление 7–12 минут, затем работа экспертов по формату встречи.
  • После экспертной встречи каждый написал собственную обязательную рефлексию до командного обсуждения, согласно заданию. Без неё КТ не засчитывается.

Реальные кастдевы нужны для проверки бизнес-гипотезы. В переданном чек-листе не задано обязательное число новых интервью как отдельное условие сдачи КТ-3. Личные прохождения A/B старого архива не переносим на новый сценарий.
