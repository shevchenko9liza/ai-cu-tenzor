# Техническая проверка прототипа оборудования ТЭС

Проверка агента, 25.10.2026. Это тест интерфейса на вымышленных примерах. Он не является личным прохождением Елизаветы, исследованием с инженером, валидацией модели или проверкой реального оборудования.

## Как воспроизвести

Открыть `lab05/prototype.html` в браузере. Обе подготовленные PNG-схемы, библиотека Three.js и код встроены в HTML. Этот файл работает отдельно, без сервера и соседних файлов. При недоступном WebGL остаются пояснение, кнопки узлов и основной рабочий путь. Поля и задания хранятся в текущей сессии до перезагрузки; задание и схема скачиваются из встроенных данных.

Для автоматической проверки из корня репозитория нужны Node.js, зависимости `package.json` и Chromium Playwright:

```sh
npm install
npx playwright install chromium
npm run build
npm test
npm run test:decision-support
npm run test:archive
```

Вспомогательный [archive-check.html](archive-check.html) сохранён побайтово относительно предыдущего прототипа. Отдельный скрипт `scripts/check-archive.mjs` прошёл 24 проверки. Его прежние сценарии и журнал доступны в файлах с префиксом `archive-`. Они не подменяют новый основной путь.

## Чего этот результат не подтверждает

Самостоятельное понимание инженером, применимость выбранных датчиков на конкретной станции, диагноз, прогнозируемость отказов, срок предупреждения, качество модели, предотвращённые простои и готовность платить требуют отдельных проверок. Согласование команды и личное прохождение новой версии ещё не получены.

Отдельно проверены привязка меток к вращающимся узлам и отсутствие ссылок на архив, бизнес-документы и КТ-3 в рабочем интерфейсе.

Дополнительно проверены четыре шага осмотра, смена версии, приостановка прогноза по измерениям и режиму, формула горизонта и достигнутая граница, редактируемые затраты, резерв без потерь выпуска, отрицательный эффект, необязательная вероятность и снимок проверок в скачанном задании. Отдельный скрипт `check-decision-support.mjs` проверяет алгебру и граничные случаи.

## Автономная схема после исправления

В видимой вкладке схема не загружалась: локальный сервер 127.0.0.1:8768 перестал отвечать, а изображение запрашивалось отдельным файлом. Теперь `prototype.html` собирается из шаблона и включает обе схемы, Three.js, код 3D и расчётов. PNG встраиваются без изменения байтов; сборка проверяет контрольные суммы именно обрезанных публичных файлов. Ссылка на отдельную картинку заменена скачиванием встроенного изображения.

В автоматическом прогоне один HTML копируется во временную пустую папку, сеть отключена. Проверяются все основные пути, обе схемы, их увеличение и переходы, а скачанный PNG побайтово сравнивается с подготовленным источником. Ни одного внешнего запроса за ресурсами не требуется. Для изменения UI редактируется `prototype.template.html`; сборщик — `scripts/build-prototype.mjs`.
