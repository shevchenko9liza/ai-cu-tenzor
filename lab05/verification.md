# Техническая проверка прототипа оборудования ТЭС

Проверка агента, 25.10.2026. Это тест интерфейса на вымышленных примерах. Он не является личным прохождением Елизаветы, исследованием с инженером, валидацией модели или проверкой реального оборудования.

## Как воспроизвести

Распаковать комплект целиком и открыть `lab05/prototype.html`. Соседние `pump-view.js` и `vendor/three.min.js` нужны для 3D-схемы. Сеть не требуется. При недоступном WebGL вместо модели остаётся пояснение, кнопки узлов и основной рабочий путь. Поля и задания хранятся в текущей сессии до перезагрузки; выгрузка доступна отдельным текстовым файлом.

Для автоматической проверки из корня репозитория нужны Node.js, зависимости `package.json` и Chromium Playwright:

```sh
npm install
npx playwright install chromium
npm run build
npm test
npm run test:archive
```

## Проверенный результат

Основной макет: **24 группы проверок пройдены**, Chromium 151.0.7922.34. Окна 1440×1080 и 390×844. Ошибок JavaScript: 0. HTTP-запросов при автономном прохождении: 0. Максимум измеренного взаимодействия в этом прогоне: 325 мс. Это результат локального теста, не промышленный SLA.

Проверены 3D-отрисовка и управление клавиатурой, внутренние узлы и сброс вида, связь выбранного узла с объяснением, пояснения всех шести показателей, фильтры, графики, обязательные поля, черновики и возвраты, выгрузка текста, исход задания, запрос на данные и отдельная повторная проверка. Проверены нормальный и резервный режимы, журнал, очистка при перезагрузке, мобильная раскладка и сохранение рабочего пути без WebGL.

Дополнительно проверены оценки на первом экране, загрузка схем без сети, увеличение и переход к опоре. Разрез проверен изменением изображения, состояния и подписи; мобильная схема прокручивается внутри своего блока. Визуально просмотрены основной экран, карточка, разбор, форма, результат, отсутствие данных и мобильные варианты. Размеры окон не означают проверку всех браузеров и всех устройств.

## Сохранённая проверка архива

Вспомогательный [archive-check.html](archive-check.html) сохранён побайтово относительно предыдущего прототипа. Отдельный скрипт `scripts/check-archive.mjs` прошёл 24 проверки. Его прежние сценарии и журнал доступны в файлах с префиксом `archive-`. Они не подменяют новый основной путь.

## Чего этот результат не подтверждает

Самостоятельное понимание инженером, применимость выбранных датчиков на конкретной станции, диагноз, прогнозируемость отказов, срок предупреждения, качество модели, предотвращённые простои и готовность платить требуют отдельных проверок. Согласование команды и личное прохождение новой версии ещё не получены.

Отдельно проверены привязка меток к вращающимся узлам и отсутствие ссылок на архив, бизнес-документы и КТ-3 в рабочем интерфейсе.
