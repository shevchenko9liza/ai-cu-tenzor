Лаборатория 5 · задания 4–6

Статус: версия после замечаний из переданного отчёта 25.10.2026. Отчёт описывает делегированное прохождение предыдущего интерфейса. Связи с US1–US5. Реальное пользовательское тестирование ещё не проводилось.

C1. Разобрать согласованный набор

Цель: получить обоснованный следующий шаг. Инициатор: инженер станции. Условие: выбран учебный набор A с указанными метаданными и журналом событий. Результат: технические условия в учебном примере согласованы; нужен отдельный проект эксперимента.

Шаг Действие инженера Видимый ответ продукта
1 Выбирает набор A для заданной цели Описание, объект и период на карточке; цель и учебный характер указаны до открытия паспорта
2 Открывает паспорт Параметры, время и журнал событий; происхождение всех значений обозначено как демонстрационное
3 Запускает проверку Замечания и ограничения; нет реального серверного анализа
4 Читает вывод «Можно готовить эксперимент» с оговоркой: качество прогноза ещё не проверено
5 Готовит план, при наличии согласования заполняет ответственного, срок и результат каждого действия Действия по разбору отказа и согласованию эксперимента. Поля изначально пустые, человек может оставить их незаполненными
6 Скачивает и открывает план, сопоставляет с экраном либо возвращается Файл содержит набор, статус, вывод, ограничения и заполненные поля. Из плана можно вернуться к результату без потери записей

C2. Уточнить метаданные и продолжить

Цель: снять исправимую неопределённость, не выдать догадку за факт. Условие: набор B, часовой пояс неизвестен. Результат зависит от наличия подтверждённого пояса.

Шаг Действие инженера Видимый ответ продукта
1 Выбирает B, читает паспорт и запускает проверку «Нужно уточнить время» и причина: нельзя надёжно сопоставить сигнал и событие
2 Переходит к уточнению Поле пояса, варианты «Не знаю» и «UTC+3 подтверждён владельцем архива»
3а Выбирает подтверждённый UTC+3 и нажимает «Сохранить уточнение» Отдельный экран «Уточнение сохранено» с кнопкой повтора. Одного выбора значения недостаточно
4а Нажимает «Повторить проверку» Новый вывод и статус «Время уточнено: UTC+3»; старый результат заменён
3б Оставляет «Не знаю», пробует «Сохранить уточнение» Ошибка у поля, фокус возвращается к нему. Неизвестное значение не становится подтверждённым
4б Нажимает «Подготовить запрос» План запроса сведений владельцу; результат продолжает требовать уточнения
5 Заполняет согласованные поля плана, скачивает и открывает файл После повтора — план эксперимента со статусом уточнения; при неизвестном поясе — запрос. Записи запроса не переносятся автоматически в план эксперимента

Возврат сохраняет текущий набор и его записи. При смене архива с уточнением или заполненными полями плана появляется предупреждение: можно остаться на текущем наборе или подтвердить сброс. Подтверждение очищает уточнения, результат и поля плана. Скачанные файлы остаются на устройстве. Нельзя получить положительный вывод для B простым переходом назад/вперёд.

C3. Получить отрицательный результат

Цель: понять, почему пока нельзя оценивать прогноз отказов. Условие: набор C без журнала событий. Результат: список недостающих материалов и адресат запроса по роли.

Шаг Действие инженера Видимый ответ продукта
1 Выбирает C, изучает паспорт Показания есть, журнал событий отсутствует
2 Запускает проверку «Нужна история событий»; нельзя проверить, какие предупреждения предшествовали отказам
3 Читает ограничения Это ограничение проверки прогноза отказов, не запрет всех видов анализа
4 Готовит следующий шаг Запросить дату/время, оборудование, вид события, ремонт, источник и достоверность записи
5 Сохраняет план Отрицательный результат и причина сохранены; нет фиктивной кнопки «всё исправлено»

Пользователь может выбрать другой готовый набор. Настоящая загрузка журнала и изменение задачи исследования в макет не входят.

5. Общая карта

Выбор архива → паспорт → проверка → вывод → план.

C2, подтверждённый пояс: результат → уточнение → выбор UTC+3 → «Сохранить уточнение» → экран «Уточнение сохранено» → «Повторить проверку» → новый результат → план.

C2, неизвестный пояс: результат → уточнение → «Не знаю» → попытка сохранить → сообщение об ошибке. Затем «Подготовить запрос» → план запроса владельцу. Запрос также доступен непосредственно с результата B.

C3: ограничение прогноза отказов → план запроса истории событий. Получение реальных сведений остаётся за пределами макета.

Возвраты: план → результат → паспорт; уточнение → результат; сохранённое уточнение → паспорт или повторная проверка; паспорт → выбор архива. С экрана выбора паспорт доступен после выбора набора.

Смена набора: при наличии уточнения или заполненных полей — предупреждение → отмена с сохранением текущего набора либо подтверждение сброса. Без таких записей смена происходит сразу. Пустой старт вызывает просьбу выбрать пример.

Сохранение: план → скачивание .txt → открытие файла пользователем и сверка набора, статуса и записей. Открытие файла происходит средствами браузера или операционной системы.

US Сценарии Экран/состояние и переход
US1 C1–C3 Выбор и паспорт
US2 C1–C3 Паспорт и проверка
US3 C2 Уточнение, ошибка, сохранённые сведения, отдельный повтор; запрос неизвестного
US4 C1–C3 Три разных вывода с ограничениями
US5 C1–C3 Поля плана, скачивание, возврат с записями; предупреждение перед сбросом

Собственный интерфейс выбран для конкретной рабочей задачи инженера: разобраться в состоянии набора и получить согласуемый следующий шаг. Проверить, нужен ли отдельный интерфейс вместо существующих инструментов, предстоит на кастдеве.

6. Прототип и проверка

Открыть отдельный HTML-прототип. Реальные ИИ, сервер и файлы станции не подключены. ФТ и НФТ описывают ожидаемое поведение. Технические проверки агента записываются отдельно от личного журнала.

Личный проход 1: набор A → паспорт → проверка → план → сохранение. Объяснить своими словами, что уже проверено и чего ещё недостаточно для обещания прогноза.

Личный проход 2: набор B → замечание о времени → попытка оставить неизвестное → подтверждённый пояс → повторная проверка → новый план. Проверить также отрицательный C: результат не должен предлагать запуск модели.

Переданный отчёт фиксирует делегированное прохождение исходной версии. По его замечаниям обновлены интерфейс и сценарии. Самостоятельное ручное прохождение студенткой отдельно не зафиксировано. Обновлённую версию нужно содержательно проверить после правок.
